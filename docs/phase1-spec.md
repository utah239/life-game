## 目的

Phase 0(`../phase0/`)で検証した技術要素を統合し、**1人で遊べる最小限の人生
シミュレーション**を作る。plan.mdの構想全体の実装ではない。ここに書かれていないものは
対象外。

## スコープ(これだけ作る)

- 1人プレイのみ
- 長編モードのみ(短編は対象外)。**時間粒度は1ターン=1ヶ月、1年=12ターンで固定**
  (2026-08-12決定、plan.md「世界の時間の流れ方」参照。この仕様の旧版は「数日〜数週間」
  としていたが、マルチプレイの公平性を優先してplan.md側の「1ヶ月単位」に統一した)
- **資源**: time / energy / peace / money / trust(Phase 0と同じ5種)
- **ストック資産(money / trust)に維持コストを追加する**: 何もしなくても緩やかに
  目減りする(エントロピー原則の実装。減衰率は小さく、対価を払う行動で相殺できる程度)
- **契約・債務テーブル**: 「相手・内容・期限・履行状態」を持つレコード。プレイヤーの
  選択が約束・借りを生む場合はここに記録し、期限が来たら履行/不履行を次の状況生成の
  材料にする(LLMには自由に判定させず、テーブルの状態をコードが管理する)
- **ターンの構造**:
  1. 状況提示 + 3択(money型/labor型/social型。コストはコード側のアーキタイプ
     テーブルが決定。Phase 0 `--cost-mode code` と同じ)
  2. プレイヤーが選択
  3. 整合性担保役(絶対法則=資源保存則・エントロピー違反のみをチェックする軽量
     プロンプト。Phase 0 `--consistency-check` と同じ)
  4. ナレーション(数値に言及しない結果描写)
- **世界状態**: イベントソーシング(`events.jsonl` への追記 → `reduce_state()` で
  現在状態を再構築)。既存資源に加え、契約・債務テーブルも同じログに乗せる
- **常時稼働の再定義**: イベントループ(LLM呼び出しを伴う処理)はプレイヤーが操作して
  いる間だけ回す。誰も見ていない間は何も処理しない(Phase 1では常時稼働の共有世界は
  作らないため、この論点は次のフェーズまで先送りでよい)

## 対象外(明示的に凍結。触らない)

世代交代、マルチプレイ、常時稼働の共有世界、所有権レジームのDDL実装、再帰的司法責任・
司法審査役、警察・犯罪、革命・投票、社会システムの変化経路、テンソル背景シミュレーション、
短編モード、所有権判定の3経路(記録/執行力/力による書き換え)。

いずれも面白い設計だが、1人プレイのPhase 1では一切画面に出ない。手を出さないこと。

## 実装の土台

`life-game/phase0/game.py` をベースに拡張する。既に実装・検証済みの要素:
- イベントソーシング(`reduce_state`, `append_event`)
- コスト決定のコード化(`--cost-mode code`, `ACTION_ARCHETYPES`)
- 整合性担保役ロール(`--consistency-check`, `CONSISTENCY_SYSTEM`)
- キー名のホワイトリスト検証・クリップ(`sanitize_cost`)
- `keep_alive` の明示設定

事前の技術検証結果(レイテンシ・日本語品質・モデル選定)は `../phase0/README.md` を参照。

## 完了の目安

- 1キャラクターが複数ターン(10〜20程度)を通して、契約・債務が発生→期限到来→履行/
  不履行まで一貫して機能する
- ストック資産の維持コストが体感できる(何もしないと目減りする)
- 意味論的な破綻(行動の意味とコストの向きが矛盾する等)が起きない
- 状況の繰り返し問題(Phase 0で未解決)への対策を最低1つ試す
